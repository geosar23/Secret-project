Badges show status as a dot plus a label in a round pill.

Use `.badge` with `badge-success`, `badge-warning`, `badge-error`, `badge-info` or `badge-gray`. Map request statuses as in the README: Pending warning, Approved success, Rejected error, Canceled gray, Needs routing info. Never use `mat-chip` for status. Always include the text; colour alone is not enough.

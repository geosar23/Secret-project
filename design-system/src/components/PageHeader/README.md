The page header opens every screen with a title, an optional subtitle and a right-aligned action group.

The shared component is `app-page-header` (`title`, `subtitle` inputs; actions projected). The title is an `h3`, the subtitle 13px secondary text. Actions sit in a row with a 10px gap; the primary action goes last. The primary action is a `mat-flat-button` with a leading `add` icon, exactly like "Create user" on the users page (see Button). The header wraps on narrow screens.
